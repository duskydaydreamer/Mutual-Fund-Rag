# Mutual Fund FAQ frontend

- This workspace contains the React frontend for a facts-only mutual fund RAG assistant.
- Preserve the current professional financial SaaS design, responsive behavior, light/dark modes, and accessibility.
- Keep the disclaimer prominent: the assistant provides factual information only and no investment advice.
- Keep assistant answers concise and always retain source and last-updated fields when backend data is connected.
- Use the existing React, TypeScript, Vinext, CSS, and Lucide architecture. Do not replace the working stack.
- Run the local interface with `npm run dev:local`; it must be available at `http://localhost:3000`.
- Run `npm run build` before considering implementation work complete.
- Do not modify the parent Python RAG pipeline unless the user explicitly asks for backend integration.
